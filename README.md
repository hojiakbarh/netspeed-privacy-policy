## 1. Introduction

NetSpeed ("the App") is a free Android application that monitors
internet speed, counts steps, and tracks GPS-based movement speed.
This Privacy Policy explains how the App handles your information.

---

## 2. Data We Do NOT Collect

NetSpeed does **not**:
- Collect or store personal information
- Send any data to external servers
- Create user accounts
- Track your identity
- Share data with third parties
- Use analytics or crash reporting services

---

## 3. Data Stored Locally on Your Device

All data is stored **only on your device** and is never transmitted:

| Data | Purpose | Where stored |
|------|---------|-------------|
| Daily internet usage (MB) | Usage statistics | Device only |
| Monthly internet usage (MB) | Usage history | Device only |
| WiFi usage (MB) | WiFi tracking | Device only |
| Mobile data usage (MB) | Mobile tracking | Device only |
| Step count | Pedometer | Device only |
| App settings | Preferences | Device only |

You can delete all data anytime from:
**Settings → Data Management → Clear Today's Data**

---

## 4. Permissions Explained

| Permission | Why needed | When used |
|------------|-----------|-----------|
| INTERNET | Measure network speed | Always (speed meter) |
| ACCESS_NETWORK_STATE | Detect WiFi/Mobile | Always |
| ACCESS_FINE_LOCATION | GPS speed tracking | Only when user starts Speed screen |
| ACTIVITY_RECOGNITION | Step counting | Only when user starts Steps screen |
| FOREGROUND_SERVICE | Keep speed meter active | Always (notification) |
| POST_NOTIFICATIONS | Show speed notification | Always |
| SYSTEM_ALERT_WINDOW | Optional screen overlay | Only if user enables it |

**Important:** Location data is used only in real-time to calculate
movement speed. It is never stored or transmitted anywhere.

## 5. Advertising

The free version of NetSpeed may display advertisements served by
**Google AdMob**. AdMob may collect device identifiers according to
[Google's Privacy Policy](https://policies.google.com/privacy).

You can manage ad preferences through your device's Google settings.

## 6. Children's Privacy

NetSpeed does not knowingly collect data from children under 13.
The app is rated "Everyone" and contains no inappropriate content.

## 7. Security

All data is stored using Android's secure SharedPreferences system.
No data is transmitted over the internet (except for the speed test
feature which connects to public speed test servers).
